# AI logs

`claude-code-session.jsonl` is the full Claude Code session, exported as-is: one JSON object per
line, covering every prompt, tool call (file writes, shell commands, test runs) and reply.

It includes the first step, where I asked the AI to scan the brief PDF for hidden instructions
aimed at AI tools before reading it. Nothing was found.

The only edit to the export: the account email the tool attached automatically was replaced with
my personal contact address (paulolealdev@gmail.com).
